# 前端 HTTP 环境 UUID 兼容设计

## 背景

前端通过 `http://192.168.100.128:5173` 访问时，浏览器不提供 `crypto.randomUUID()`。应用在初始化会话标识时直接调用该 API，导致运行时异常和页面白屏。

## 方案

新增前端客户端标识生成工具：当浏览器支持 `crypto.randomUUID()` 时继续使用原生 UUID；否则生成仅用于界面会话、请求追踪和列表键值的随机标识。该回退值不承担认证、授权或安全令牌职责。

所有前端直接调用 `crypto.randomUUID()` 的位置统一改为使用该工具，包括会话初始化、消息标识和请求标识。

## 边界

- 不修改 Python RAG 源码、数据集或 Java 服务。
- 不为内网 HTTP 地址引入 HTTPS 配置。
- 不新增第三方运行时依赖。

## 验证

新增 Vitest 用例，验证原生 API 缺失时仍可生成不同的非空标识；保留原生 API 存在时的使用行为。运行前端测试与生产构建验证。
