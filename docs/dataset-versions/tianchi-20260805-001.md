# 天池商品目录版本：tianchi-20260805-001

## 用途

本说明定义项目当前使用的本地演示商品目录版本。它让团队成员在已取得数据使用资格的前提下，独立生成相同的 5,000 条商品目录；本仓库不再分发原始数据、商品图片或生成后的数据库。

## 数据来源与许可

- 数据集：天池“淘宝穿衣搭配数据集”（数据集 ID：52）
- 发布页：<https://tianchi.aliyun.com/dataset/52>
- 数据集页面标注许可：`CC BY-SA-NC 4.0`
- 使用要求：遵守天池页面、数据集许可和所在团队的使用要求；使用或展示时保留来源与许可说明；不得把原始数据或其下载链接提交到本仓库。

| 项目 | 值 |

## 获取并放置原始文件

在天池页面取得访问资格后，下载以下文件：

| 天池下载文件 | 项目内放置位置 |
| --- | --- |
| `dim_items (new).txt` | `backend/data/raw/tianchi/dim_items.txt` |
| `tianchi_fm_img3_1.zip` | `backend/data/raw/tianchi/archive/tianchi_fm_img3_1.zip` |

解压图片。大型 ZIP 建议使用 `tar`，不要依赖 PowerShell 的 `Expand-Archive`：

```powershell
tar -xf backend\data\raw\tianchi\archive\tianchi_fm_img3_1.zip -C backend\data\raw\tianchi\images
```

解压后的图片文件应位于 `backend/data/raw/tianchi/images/` 的子目录中，且文件名为商品 ID。

## 导入命令

在项目根目录执行：

```powershell
backend\.venv\Scripts\python.exe backend\scripts\import_tianchi_fashion_collection.py `
  --items backend\data\raw\tianchi\dim_items.txt `
  --images-dir backend\data\raw\tianchi\images `
  --sample-size 5000 `
  --seed 42 `
  --out-dir backend\data\tianchi-catalog
```

导入结果会生成到被 Git 忽略的 `backend/data/tianchi-catalog/`，包括 `articles_sample.csv`、`images/` 和 `catalog_manifest.json`。

## 校验

导入后执行：

```powershell
$catalog = "backend\data\tianchi-catalog"
(Import-Csv "$catalog\articles_sample.csv").Count
(Get-ChildItem "$catalog\images" -Recurse -File).Count
(Get-FileHash "$catalog\articles_sample.csv" -Algorithm SHA256).Hash.ToLower()
Get-Content "$catalog\catalog_manifest.json"
```

前三项依次应为：`5000`、`5000`、`45829d1c2e13a92a3a91d323758cf151ff6c98f54b9f9c012e08ee99aeb6931f`。若结果不同，先检查原始文件是否完整、图片是否正确解压，以及导入脚本版本是否与本仓库一致。
