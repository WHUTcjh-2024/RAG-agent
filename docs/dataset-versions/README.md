# 数据版本说明

本目录只保存可公开共享的**数据版本说明**，用于让团队成员在各自已获授权的环境中复现相同的本地商品目录。

不会提交下列内容：

- 天池下载的原始压缩包、元数据和图片；
- 导入生成的商品 CSV、图片目录、SQLite 数据库和向量索引；
- 任何访问令牌、签名下载链接或个人下载记录。

## 当前版本

- [tianchi-20260805-001](tianchi-20260805-001.md)：基于天池“淘宝穿衣搭配数据集”的 5,000 条固定抽样目录。

## 协作规则

1. 团队成员自行从原始数据发布页获取具有使用权限的数据，不从 GitHub 仓库复制原始数据。
2. 按版本说明中的文件名、抽样数量和随机种子导入。
3. 导入完成后校验商品数、图片数和 `catalog_manifest.json`；不一致时不要将本地生成文件加入 Git。
4. 如需创建新版本，新增一个版本说明文件，不修改既有版本的参数或校验值。
